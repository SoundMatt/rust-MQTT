## Gap summary for DAL-A/B

If rust-MQTT is to be used at DAL-A or DAL-B, the following additional work
is required:

1. **Separate Low-Level Requirements (LLR)** documents
2. **MC/DC structural coverage** measurement and test augmentation
3. **Formal tool qualification** for `rustc` at TQL-1 or TQL-2
4. **Formal methods** for wildcard matching (`match_topic`) — candidate for
   formal verification given its safety impact (FMEA-005, ASIL-B)
5. **Independent Software Verification** (ISV) by a qualified third party
